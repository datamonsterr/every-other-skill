# Requirements: shop assistant service

Build a small service for the corner shop:
- An HTTP API used by an Expo mobile app: price list, sales, daily totals.
- A chat endpoint where the owner asks questions in Vietnamese ("how much rice did we sell this week?") answered by an LLM over the shop's data.
- Runs on one cheap VPS or a free-tier platform; budget under 10 USD/month.
- One developer, comfortable with TypeScript and learning Rust.
- Must be easy to back up and restore.
